# AI Trailing test videos

These six MP4 clips are derived from the official EPFL POM 1.1 synchronized multi-camera scene. The source provides two connected camera views (`CAM01` and `CAM02`) as frame sequences. Each view has been split into three short time segments so the UI and processing pipeline can test chronological trail updates.

This is a connected two-camera test pair, not six independent physical cameras. The manifest preserves the source frame ranges and attribution. It is suitable for testing synchronized observation ordering, camera transitions, track history, and trail rendering. It is not evidence of a real border deployment.
